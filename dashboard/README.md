# Space Jump - Analytics Command Center

Standalone telemetry, marketing attribution, economy balancing, and diagnostics app.

## Launch
- **Port 3001:** `npm run serve:dashboard` or `node dashboard/server.js` -> `http://localhost:3001`
- **Port 3000:** `npm start` -> `http://localhost:3000/dashboard`
- **File Access:** Open `dashboard/index.html` directly in browser.
- **PIN Gate:** Master Developer PIN: `2026`

## Modules
1. **Executive KPIs:** Live players, sessions, altitude records, 7-day timeline.
2. **Distribution & Attribution:** UTM source/campaign tracking, conversion funnel, K-factor virality.
3. **Gameplay Telemetry:** Altitude drop-off heatmap, ship pick-rates, death taxonomy (void, fragile, mines).
4. **Economy:** Coin/crystal sinks vs faucets, hangar unlock progression.
5. **Diagnostics:** OS/platform breakdown, FPS telemetry, client errors.
6. **Data Tools:** Real-time event explorer, CSV export, raw JSON dump.
